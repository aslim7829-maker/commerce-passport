How the flow works

1. Current owner requests

The backend verifies that the signed-in user owns the selected product.

2. Recipient reviews

Only the account named as recipient can accept or reject the request.

3. Ownership is updated

On acceptance, the server rechecks the existing owner and updates the product in one transaction.

4. Both users can see history

Requests remain visible with their status, subject to the backend function's access checks.
